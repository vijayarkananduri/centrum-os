# Centrum OS Configuration Reference
# All available settings and options

## User Settings
USER_NAME="User"              # Your name for personalization
USER_EMAIL=""                 # Email (optional)

## Path Configuration
PROJECT_PATHS="$HOME/projects:$HOME/work"  # Colon-separated project directories
EDITOR="nvim"                 # Default editor (nvim, vim, nano, etc.)
BROWSER="w3m"                 # Text-based browser for viewing links

## Behavior Settings
AUTO_GREET="true"             # Show greeting on new session
THEME_AUTO="true"             # Auto-switch theme based on time
FOCUS_BLOCK_DISTRACTIONS="false"  # Block distracting sites during focus
NEWS_DEFAULT_SOURCE="hackernews"  # Default news source

## Time Configuration
WORK_DAY_START="08:00"        # Start of work day
WORK_DAY_END="18:00"          # End of work day
FOCUS_DEFAULT_MINUTES="45"    # Default focus duration
